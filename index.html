Through Line

직업은 바뀌어도 문제를 푸는 방식은 같았습니다.

관찰에서 시작해 사용자와 데이터로 검증하고, 작동하는 해법을 다음 사람이 다시 쓸 수 있게 남깁니다.

고등학교 때는 안전한 믹서기를 시제품으로 만들었고, 대학에서는 사용자 조사로 사회문제 해결 아이디어를 검증했습니다. 지금은 같은 방식으로 캠페인의 병목을 찾고, 검증된 해법을 운영 시스템으로 남깁니다.

  1. 01

    고등학교

    관찰을 시제품으로

    안전 믹서기와 데이터 보호장치를 직접 설계·제작하며, 불편을 설명하는 데서 멈추지 않는 습관을 만들었습니다.

    발명 영재반 · 시제품 제작 · 특허 출원

  2. 02

    대학 · 창업

    아이디어를 사용자 검증으로

    차량 소유자 300명 조사와 자립준비청년 지원 펀딩을 통해, 좋은 의도보다 실제 사용자의 선택이 먼저라는 기준을 익혔습니다.

    사용자 조사 300명 · 크라우드펀딩 469%

  3. 03

    2022–2025

    검증을 캠페인 성과로

    중진공과 플레이디에서 30여 브랜드를 운영하며, 고객 가설을 GA4·매체 데이터·실험으로 확인했습니다.

    정부사업 운영 · 대형 광고주 PM · IMC 재설계

  4. 04

    2025–현재

    성과를 운영 시스템으로

    HLL중앙에서 대형 통합 계정을 운영하며 재고·리포트·정산·모니터링을 자동화하고, 판단 기준을 팀의 도구로 남깁니다.

    10개 채널 통합 운영 · 자동화 6종 · 공개 교육 도구

사람이 기억해서 확인하던 업무를 자동화하고, 데이터가 이상하면 스스로 멈추도록 설계했습니다. 실행 속도보다 안전장치를 먼저 설계했습니다 — 정상이라는 증거가 없으면 광고를 건드리지 않고 멈춥니다.

  • S1

    재고 연동 쇼핑검색 자동 운영

    재고 데이터를 2시간 주기로 수집해 임계값 기준으로 소재를 자동 OFF·재라이브합니다. 회당 최대 900개 상품을 처리합니다.

    안전장치 · 재고 수집에 이상이 감지되면 광고를 건드리지 않고 멈춘 뒤 담당자를 호출합니다. 변경 0건으로 종료됩니다.

    약 2~3시간 → 5분 이내

  • S2

    리포트 자동화 엔진

    RAW 3종을 붙여넣으면 대시보드·캠페인 리포트·QC가 자동 생성됩니다. 매체 별칭 38종, 오디언스 82그룹을 자동 매핑합니다.

    안전장치 · 수식 오류 0건 · 전수 QA 통과

    리포트 수기 작성 단계 제거

  • S3

    무인 모니터링 3종

    데드랜딩 점검(매일 10시·16시), 검색광고 소진 흐름(3시간 주기), GA4 데일리 코멘트(6개 매체, 11시·14시)를 무인으로 실행합니다.

    안전장치 · 조치가 필요할 때만 알립니다. 정상 동작은 보고하지 않아 알림 피로를 만들지 않습니다.

    확인 업무를 스케줄러로 이전

  • S4

    광고비 정산 자동화

    인보이스·전표를 자동 매핑해 전자결재에 등록합니다. 5개 브랜드, 메타 포함 전 매체가 대상입니다.

    안전장치 · 검수 → 승인 → 실행 3단계. 당월 기준 파일이 없으면 임의 추정 대신 작업을 중단합니다.

    월 최대 84건 전량 처리 (2026.05 기준)

  • S5

    Auto Report 플랫폼

    광고주 데이터를 12개 KPI 시맨틱 레이어로 표준화해 월간 리포트 PDF를 자동 발송하는 자체 개발 시스템입니다.

    안전장치 · 멀티테넌트 구조 · 품질 게이트 내장

    월간 리포트 발송 자동화

  • S6

    업무 지식봇 2종

    업무 기록 854개 파일을 검색해 근거 파일과 함께 답하는 사내 챗봇과 팀즈 헬프봇(파일럿)입니다.

    안전장치 · 근거 없는 답변을 하지 않습니다. 출처 파일을 함께 제시합니다.

    히스토리 검색을 대화로 대체
