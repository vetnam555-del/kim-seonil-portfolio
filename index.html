Marketing operations

직접 기획·구축한 업무 자동화 6종

재고·리포트·모니터링·정산 업무를 시스템으로 옮기고, 데이터 이상 시 실행을 멈추는 운영 기준까지 정했습니다.

S1쇼핑검색 재고 자동 운영동작 재현 · 실제 운영 로그가 아닙니다

이번 회차 조회

0/ 900개 상품

정상 실행

  1. 01재고 조회회당 최대 900개 상품
  2. 02수량 기준 대조정해진 주기로 실행
  3. 03기준 미달 · 광고 중지쇼핑검색 자동 OFF
  4. 04재고 복구 · 광고 재개쇼핑검색 자동 ON
  5. 05완료약 2시간 → 5분 이내 (내부 실측 기준)

쇼핑검색 재고 자동 운영의 동작을 재현한 화면입니다. 재고를 정해진 주기로 조회해 회당 최대 900개 상품을 처리하고, 수량 기준에 따라 쇼핑검색 광고를 자동으로 끄거나 다시 시작합니다. 수기로 약 2시간이 걸리던 점검이 5분 이내로 줄었습니다(내부 실측 기준). 수집에 이상이 감지되면 광고를 건드리지 않고 멈춘 뒤 담당자를 호출하며, 변경 0건으로 종료합니다.

  1. S1쇼핑검색 재고 자동 운영시즌마다 바뀌는 수백 개 SKU를 수기로 확인했습니다.
  2. S2이상 징후 자동 모니터링 3건열리지 않는 랜딩 페이지(데드랜딩), 소진 흐름 정체, 매체별 성과 코멘트를 사람이 기억해서 확인해야 했습니다.
  3. S3리포트 자동 생성 시스템데일리·위클리 리포트를 매번 수기로 작성하면서 매체 별칭과 오디언스 그룹을 사람이 매핑해야 했습니다.
  4. S4광고비 정산 자동화법인카드 광고비 증빙을 결제 내역·계정·적요와 대조해 전자결재에 수기로 등록해야 했습니다.
  5. S5월간 리포트 자동 발송 시스템광고주별로 지표 정의와 리포트 양식이 달라 매월 같은 작업을 반복했습니다.
  6. S6업무 지식봇 2종휴가·대직 상황에서 과거 운영 히스토리를 찾는 데 시간이 걸렸습니다.
