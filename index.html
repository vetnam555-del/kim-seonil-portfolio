Marketing operations

직접 기획·구축한 업무 자동화 6종

사람이 반복하던 재고 확인·리포트·정산을 시스템으로 옮겼습니다. 구현은 AI 도구와 함께 했고, 언제 멈출지는 직접 정했습니다.

S1쇼핑검색 재고 자동 운영작동 방식 예시

이번 회차 조회

0/ 900개 상품

정상 실행

  1. 01재고 조회회당 최대 900개 상품
  2. 02수량 기준 대조정해진 주기로 실행
  3. 03기준 미달 · 광고 중지쇼핑검색 자동 OFF
  4. 04재고 복구 · 광고 재개쇼핑검색 자동 ON
  5. 05완료약 2시간 → 5분 이내 (내부 실측 기준)

쇼핑검색 재고 자동 운영의 동작을 재현한 화면입니다. 재고를 정해진 주기로 조회해 회당 최대 900개 상품을 처리하고, 수량 기준에 따라 쇼핑검색 광고를 자동으로 끄거나 다시 시작합니다. 수기로 약 2시간이 걸리던 점검이 5분 이내로 줄었습니다(내부 실측 기준). 수집에 이상이 감지되면 광고를 건드리지 않고 멈춘 뒤 담당자를 호출하며, 변경 0건으로 종료합니다.

  1. S1쇼핑검색 재고 자동 운영재고 수량에 따라 쇼핑검색 광고를 자동으로 끄고 다시 켭니다.점검 약 2시간 → 5분 이내 · 내부 실측
  2. S2이상 징후 자동 모니터링 3건열리지 않는 랜딩·예산 소진 정체를 예약 점검하고, 6개 매체 GA4 일일 코멘트를 AI로 작성합니다.이상이 있을 때만 알림 · 정상은 보고하지 않음
  3. S3리포트 자동 생성 시스템매체 원본 3종을 붙여넣으면 대시보드·리포트·검수표가 생성됩니다.매체 별칭 38종 · 오디언스 82그룹 자동 매핑
  4. S4광고비 정산 자동화인보이스·전표를 매핑해 전자결재에 자동 등록합니다.월 최대 84건 전량 처리 · 2026.05 기준
