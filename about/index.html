01

운영 손실을 줄이는 자동화

품절 상품이 노출되거나 데이터가 틀린 채로 광고가 계속 도는 상황을 차단합니다.

  • S1Python매체 APIGoogle Sheets

    쇼핑검색 재고 자동 운영

    기존시즌마다 바뀌는 수백 개 SKU를 수기로 확인했습니다.

    재고를 정해진 주기로 확인하고, 수량 기준에 따라 쇼핑검색 광고를 자동으로 끄거나 다시 시작합니다. 회당 최대 900개 상품을 처리합니다.

    약 2시간 → 5분 이내약 2시간 → 5분 이내약 2시간 → 5분 이내†1

    내부 실측 기준

    재고 수집에 이상이 감지되면 광고를 건드리지 않고 멈춘 뒤 담당자를 호출합니다. 변경 0건으로 종료됩니다.

  • S2PythonGA4 APIClaude · GPT

    이상 징후 자동 모니터링 3건

    기존열리지 않는 랜딩 페이지(데드랜딩), 소진 흐름 정체, 매체별 성과 코멘트를 사람이 기억해서 확인해야 했습니다.

    열리지 않는 랜딩과 검색광고 소진 정체를 정해진 시간에 점검하고, 6개 매체의 GA4 일일 코멘트를 AI로 작성합니다. 이상이 있을 때만 알립니다.

    정기 점검을 자동 실행하도록 전환

    정상 동작은 보고하지 않습니다. 알림이 왔다는 것 자체가 사람이 볼 일이 생겼다는 뜻입니다.

02

반복 업무를 자동화

리포트·정산처럼 매달 같은 손이 가던 일을 시스템으로 옮겼습니다.

  • S3Google Apps ScriptGoogle Sheets

    리포트 자동 생성 시스템

    기존데일리·위클리 리포트를 매번 수기로 작성하면서 매체 별칭과 오디언스 그룹을 사람이 매핑해야 했습니다.

    매체 원본 데이터(RAW) 3종을 붙여넣으면 대시보드·캠페인 리포트·검수표(QC)가 자동 생성됩니다. 매체 별칭 38종, 오디언스 82그룹을 자동 매핑합니다.

    수기 작성 없이 리포트 자동 생성

    검수한 리포트 템플릿 수식 오류 0건 · 전체 운영 무오류 보장과 구분

  • S4Python전자결재 연동

    광고비 정산 자동화

    기존법인카드 광고비 증빙을 결제 내역·계정·적요와 대조해 전자결재에 수기로 등록해야 했습니다.

    인보이스·전표를 자동 매핑해 전자결재에 등록합니다. 5개 브랜드, 메타 포함 전 매체가 대상입니다.

    월 최대 84건 전량 처리월 최대 84건 전량 처리월 최대 84건 전량 처리

    2026.05 기준

    검수 → 승인 → 실행 3단계. 당월 기준 파일이 없으면 임의 추정 대신 작업을 중단합니다.

  • S5PythonPostgreSQLDocker

    월간 리포트 자동 발송 시스템

    기존광고주별로 지표 정의와 리포트 양식이 달라 매월 같은 작업을 반복했습니다.

    광고주 데이터를 12개 핵심 지표의 공통 기준으로 맞추고, 월간 리포트 PDF를 자동으로 발송합니다.

    월간 리포트 발송 자동화

    광고주별 데이터를 분리해 운영하고, 발송 전에 데이터 오류를 자동으로 확인합니다.
