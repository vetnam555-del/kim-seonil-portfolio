월 10억+ 계정의 자동화는 ‘언제 멈출지’부터 설계했습니다

한 줄 요약

10개 채널과 수백 개 SKU를 사람이 기억해서 점검하는 방식에는 한계가 있었습니다. 재고·소진·소재 점검을 자동화해 내부 점검 시간을 약 2시간에서 5분 이내로 줄였고, 데이터가 이상하면 광고를 건드리지 않고 멈추도록 설계했습니다.

기간
2025.11 – 현재

계정 운영 40% · 자동화 설계·구축 100%
규모
월 10억+ · 10개 채널

근거 형태 — 실제 캠페인 사용 원본 · 내부 실행 로그 · 외부 팀 도입 사례

  • 재고·운영 점검 시간 약 2시간 → 5분 이내
  • 하루 점검 시간 단축 115분
  • 참고 · MOP 공개 팀 사례 수작업 평균 약 3시간

10개 채널과 시즌마다 바뀌는 수백 개 SKU를 통합 운영하면서, 반복 점검을 줄이고 잘못된 데이터에서는 실행을 멈추는 자동화 체계를 직접 설계·구축했습니다.

01

문제 정의

ROAS가 좋아 보여도 품절 상품이 노출되거나 소진 흐름이 멈추면 운영 손실이 생겼습니다. 내부 점검에는 하루 약 2시간이 들었고, MOP가 공개한 HLL 팀 사례에서는 수작업 평균이 약 3시간으로 소개됐습니다.

02

데이터에서 확인한 것

점검 시간을 줄이기 전에 무엇을 놓치고 있었는지부터 셌습니다. 10개 채널에 걸친 수백 개 SKU를 사람이 기억해서 확인하는 구조에서는 품절이나 소진 정체를 알아차리는 시점이 늘 한 박자 늦었습니다. 평균 시간보다 중요한 건 '이상을 언제 알아차리는가'였습니다. 그래서 자동화의 목표를 속도가 아니라 발견 시점에 뒀습니다.

03

핵심 판단

매체 ROAS만으로 예산을 판단하지 않고 재고 상태·검색 수요·매체 역할을 함께 보도록 운영 기준을 나눴습니다. 자동화는 실행 속도보다 중복 실행·오래된 데이터·매칭 오류를 먼저 막고, 데이터에 이상이 있으면 멈추도록 설계했습니다.

04

실행

  • 재고 데이터 예약 수집 → 임계값 기반 자동 판정 → 매체 API 실행(회당 최대 900개) → 시트 기록·사후 QA → 조치 필요 시에만 알림
  • 데일리·위클리 리포트를 RAW 붙여넣기만으로 대시보드·QC까지 자동 생성
  • 데드랜딩·소진 흐름 이상 징후 자동 모니터링, LG CNS MOP 기반 쇼핑검색 입찰 최적화 병행
  • 안전장치 우선 설계 — 재고 데이터 이상 시 자동 조치 중단 및 담당자 호출
  • 키워드 확장은 원본 검수 → 제외 기준 → 후보군 → 우선 검토군으로 분리하고, 실제 등록·승인 전에는 성과로 표현하지 않음

이 케이스에는 세 갈래가 있습니다

성격이 다른 세 가지가 한 계정에서 동시에 진행됐습니다. 무엇이 대표 이야기이고 무엇이 보조인지 먼저 밝힙니다.

모바일에서는 좌우로 밀어 확인할 수 있습니다.

세 갈래를 한 수치로 합치지 않습니다. 대표 지표는 재고 자동화의 내부 실측 하나뿐입니다.

'언제 멈출지'를 먼저 정한 순서

자동화에서 가장 위험한 실패는 멈추는 것이 아니라 잘못된 데이터로 계속 도는 것이었습니다. 그래서 실행 단계보다 중단 조건을 먼저 설계했습니다.

  1. 01

    ① 수집

    재고 데이터는 정해진 주기에 맞춰 불러옵니다. 이 단계가 실패하면 광고 변경이나 시트 기록을 진행하지 않습니다.

  2. 02

    ② 정합 확인

    행 수·중복·기준일이 예상 범위인지 봅니다. 어긋나면 광고를 건드리지 않고 멈춥니다.

  3. 03

    ③ 판정

    재고 수량 기준에 따라 광고를 끄거나 다시 시작할 대상을 가립니다. 회당 최대 900개 상품.

  4. 04

    ④ 실행 · 기록

    매체 API로 실행하고 시트에 남깁니다. 조치가 필요할 때만 담당자를 부릅니다.

②에서 멈추면 변경 0건으로 종료됩니다. 정상 동작은 보고하지 않아 알림 피로를 만들지 않습니다.

06

나의 역할

10개 채널 통합 운영은 팀 체제로, 재고 자동화·리포트 엔진·모니터링 시스템은 기획부터 구축·운영까지 단독으로 수행했습니다. 모든 시스템은 인수인계 패키지로 문서화되어 있습니다.

직접 수행

  • 재고 자동화·리포트 엔진·자동 점검 시스템의 기획·구축·운영 전부
  • 18,396행 원본 검수와 확장 후보 선정 기준 수립
  • 매체 성격별 예산 판단 룰북 작성
  • 데일리·위클리 코멘트 기준과 광고주 커뮤니케이션
  • 소재 기획안 작성 — 상품군·목적별 지면과 메시지를 정해 제작 요청으로 전달

함께 수행

  • 10개 채널 매체 운영은 팀 체제로 분담했습니다
  • 쇼핑검색 입찰 최적화는 LG CNS MOP 솔루션과 함께 운영했습니다

하지 않은 것

  • 브랜드 매출 전체와 오프라인 채널은 담당 범위가 아닙니다
  • 소재의 디자인·촬영 등 실제 제작과 상품 기획에는 관여하지 않았습니다

07

실패와 배운 것

되지 않았던 것

과거 파워링크 귀속 ROAS 13,846.66%만 보면 즉시 확장해도 될 것처럼 보였습니다. 그러나 브랜드검색 원본에는 비용이 없고 증분 효과도 확인할 수 없었습니다. 그래서 이 수치를 브랜드검색 성과나 예산 확대 근거로 쓰지 않고 후보 선정 참고치로만 제한했습니다.

다음에 다르게 할 것

자동화와 분석 모두 빠른 실행보다 멈춤 기준이 중요했습니다. 데이터가 없거나 범위가 맞지 않으면 실행하지 않는 규칙이 대형 계정의 운영 신뢰도를 지켰습니다.

08

실행 화면과 증빙

공개 자료는 실제 운영·집행 맥락을 확인할 수 있는 범위만 선별했으며, 제작물과 개인 기여 범위는 캡션에서 구분했습니다.

개인 기여도는 자동화 설계서·실행 로그·인수인계 문서로 보유하고 있으며, 광고주 보안상 인터뷰에서 비식별 범위로 확인해 드립니다.

09
