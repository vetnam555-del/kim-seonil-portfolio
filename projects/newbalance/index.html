뉴발란스

월 10억 운영을 자동화하되, 데이터가 틀리면 멈추게 했습니다

한 줄 요약

10개 채널과 수백 개 SKU를 운영하면서 재고·소진·소재 점검을 자동화했습니다. 내부 점검 약 2시간, MOP가 공개한 팀 사례 평균 약 3시간이던 작업을 5분 이내로 줄였고, 이상 데이터에서는 광고를 건드리지 않도록 멈춤 규칙을 넣었습니다.

기간
2025.11 – 현재
역할
통합 매체 운영 · 자동화 설계/구축
기여 범위
계정 운영 40% · 자동화 설계·구축 100%
규모
월 10억 · 10개 채널

근거 형태 — 내부 실행 로그 · 외부 팀 도입 사례

  • 재고·운영 점검 시간 약 2~3시간 → 5분 이내
  • 리포트 수기 작성 필요 → 제거
  • 키워드 원본 검수 18,396행 · 중복 0건

10개 채널과 시즌마다 바뀌는 수백 개 SKU를 통합 운영하면서, 반복 점검을 줄이고 잘못된 데이터에서는 실행을 멈추는 자동화 체계를 직접 설계·구축했습니다.

업종
스포츠 · 패션
담당 매체
네이버 SA·BSA·GFA·쇼핑 · 구글 · 메타 · 카카오 · 크리테오 · RTB하우스 · 페이코

근거 미리보기

공개 원문은 새 창에서 확인할 수 있으며, 개인 기여도는 내부 근거와 분리해 설명합니다.

성과

재고·운영 점검 시간

약 2~3시간→5분 이내

내부 일평균 약 2시간 · 공개 팀 사례 평균 약 3시간

리포트 수기 작성

필요→제거

대시보드·QC 자동 생성

키워드 원본 검수

18,396행 · 중복 0건

23열 원본 기준

확장 검토 범위

639개 후보→우선 15개

제외 기준 적용

01

문제 정의

ROAS가 좋아 보여도 품절 상품이 노출되거나 소진 흐름이 멈추면 운영 손실이 생겼습니다. 내부 점검에는 하루 약 2시간이 들었고, MOP가 공개한 HLL 팀 사례에서는 수작업 평균이 약 3시간으로 소개됐습니다.

02

분석 근거

확장 키워드 검토에서도 큰 ROAS를 바로 성과로 쓰지 않았습니다. 18,396행·23열 원본의 중복 0건을 확인하고 제외 기준을 거쳐 639개 후보, 우선 검토 15개를 나눴습니다. 이 15개의 과거 파워링크 매체 귀속 ROAS는 13,846.66%였지만, 브랜드검색 원본에는 비용이 없어 브랜드검색 ROAS를 계산할 수 없었고 증분 성과도 아니어서 후보 선정 참고치로만 사용했습니다.

03

전략

매체 ROAS만으로 예산을 판단하지 않고 재고 상태·검색 수요·매체 역할을 함께 보도록 운영 기준을 나눴습니다. 자동화는 실행 속도보다 중복 실행·오래된 데이터·매칭 오류를 먼저 막는 fail-closed 구조로 설계했습니다.

04

실행

  • 재고 데이터 2시간 주기 수집 → 임계값 기반 자동 판정 → 매체 API 실행(회당 최대 900개) → 시트 기록·사후 QA → 조치 필요 시에만 알림
  • 데일리·위클리 리포트를 RAW 붙여넣기만으로 대시보드·QC까지 자동 생성
  • 데드랜딩·소진 흐름 무인 모니터링, LG CNS MOP 기반 쇼핑검색 입찰 최적화 병행
  • 안전장치 우선 설계 — 재고 데이터 이상 시 자동 조치를 멈추고 사람을 호출
  • 키워드 확장은 원본 검수 → 제외 기준 → 후보군 → 우선 검토군으로 분리하고, 실제 등록·승인 전에는 성과로 표현하지 않음

05

나의 역할

10개 채널 통합 운영은 팀 체제로, 재고 자동화·리포트 엔진·모니터링 시스템은 기획부터 구축·운영까지 단독으로 수행했습니다. 모든 시스템은 인수인계 패키지로 문서화되어 있습니다.

직접 수행

  • 재고 자동화·리포트 엔진·자동 점검 시스템의 기획·구축·운영 전부
  • 18,396행 원본 검수와 확장 후보 선정 기준 수립
  • 매체 성격별 예산 판단 룰북 작성
  • 데일리·위클리 코멘트 기준과 광고주 커뮤니케이션

함께 수행

  • 10개 채널 매체 운영은 팀 체제로 분담했습니다
  • 쇼핑검색 입찰 최적화는 LG CNS MOP 솔루션과 함께 운영했습니다

하지 않은 것

  • 브랜드 매출 전체와 오프라인 채널은 담당 범위가 아닙니다
  • 소재 제작과 상품 기획에는 관여하지 않았습니다

기여 범위계정 운영 40% · 자동화 설계·구축 100%

06

배운 것

되지 않았던 것

과거 파워링크 귀속 ROAS 13,846.66%만 보면 즉시 확장해도 될 것처럼 보였습니다. 그러나 브랜드검색 원본에는 비용이 없고 증분 효과도 확인할 수 없었습니다. 그래서 이 수치를 브랜드검색 성과나 예산 확대 근거로 쓰지 않고 후보 선정 참고치로만 제한했습니다.

다음에 다르게 할 것

자동화와 분석 모두 빠른 실행보다 멈춤 기준이 중요했습니다. 데이터가 없거나 범위가 맞지 않으면 실행하지 않는 규칙이 대형 계정의 운영 신뢰도를 지켰습니다.

07

보유 증빙

개인 기여도는 자동화 설계서·실행 로그·인수인계 문서로 보유하고 있으며, 광고주 보안상 인터뷰에서 비식별 범위로 확인해 드립니다.

08

출처

자동화 운영 로그·매체 API 수집 데이터·인수인계 문서, 뉴발란스 브랜드검색 확장근거 승인 문서 기준. MOP 원문은 HLL 팀 운영의 외부 기록이며 개인 기여도 증빙은 아닙니다.
