한샘

웹·앱 데이터를 주문 기여로 연결한 풀퍼널 운영

한 줄 요약

월 최대 15억 규모 SA·DA·APP 캠페인을 운영하며, GA4와 AppsFlyer를 연결해 설치 이후 재유입·주문까지 단계별 기여를 비교해 대표 캠페인 구간 기준 ROAS 1,184%를 기록했습니다.

기간
2022.09 – 2025.11
역할
매체 운영 · 퍼널 분석 · 예산 조정안
기여 범위
20%

근거 형태 — 내부 Daily ID · GA4 · AppsFlyer

  • ROAS 1,184%
  • 주문금액 약 85.3억
  • 앱 설치 18.3만 건

월 최대 15억 규모의 SA·DA·APP 캠페인을 통합 운영하며, 웹 광고와 앱 설치·재유입·주문 데이터를 하나의 퍼널로 연결해 측정했습니다.

최대 월 집행 기준

01

문제

웹 광고, 앱 설치, 재유입, 구매 데이터가 서로 다른 도구에 나뉘어 있어 클릭 효율만으로는 대규모 예산의 실제 기여를 판단하기 어려웠습니다.

02

근거

GA4와 AppsFlyer를 연결해 방문·설치·재유입·주문을 단계별로 비교했습니다. 클릭이 많은 매체와 실제 주문을 만드는 매체가 항상 같지 않다는 것이 드러났습니다.

03

판단

채널을 단일 ROAS로 줄 세우지 않고 신규 유입, 앱 설치, 재참여, 주문의 역할로 나눴습니다. 예산 판단의 최종 기준은 실제 주문 기여로 두었습니다.

  1. 01

    웹·앱 데이터 연결

  2. 02

    퍼널 단계 분리

  3. 03

    주문 기여 비교

  4. 04

    예산 조정안 도출

04

실행

  • 월 최대 15억 규모 SA·DA·APP 캠페인 통합 운영
  • GA4·AppsFlyer 상세 데이터 연결
  • 퍼널 단계별 이탈과 매체 기여를 정기적으로 점검

05

결과 해석

대표 캠페인 구간에서 ROAS 1,184%, 주문금액 약 85.3억원, 앱 설치 18.3만건을 확인했습니다. 세 수치는 같은 기간의 단일 실험 결과가 아니라 운영 리포트에 남은 대표 누적 지표이므로, 월 최대 15억원의 운영 규모와 분리해 표기했습니다.

상세 수치와 집계 기준은 페이지 상단 성과 영역 및 출처에서 확인할 수 있습니다.

06

나의 역할

매체 운영, GA4·AppsFlyer 퍼널 분석, 리포팅과 예산 조정안 도출을 담당했습니다.

직접 수행

  • SA·DA·APP 캠페인 운영과 일별 성과 점검
  • GA4·AppsFlyer 기준 퍼널 분석과 주문 기여 비교
  • 매체·캠페인별 예산 조정안과 리포트 작성

함께 수행

  • 소재 제작과 앱 랜딩 개선은 제작·서비스 담당자와 함께 진행했습니다

하지 않은 것

  • 앱 제품 개발과 결제 프로세스 운영은 담당 범위가 아닙니다
  • 브랜드 전체 매출을 광고 성과로 주장하지 않습니다

기여 범위20%

07

제약과 배운 점

설치량이 많은 매체가 주문을 만드는 매체와 달랐습니다. 대형 예산일수록 마지막 기준을 주문 기여로 두는 편이 안전했습니다.

08

출처

PlayD 한샘 Daily ID Report 최종 보정본, GA4·AppsFlyer 운영 데이터 기준. 월 15억은 최대 월 집행 규모이며, ROAS·주문금액·앱 설치는 대표 캠페인 구간 누적 기준으로 서로 다른 기간을 집계한 수치입니다.
