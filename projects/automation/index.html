AI · 리포트 자동화

검증된 운영 방식을 다음 캠페인에서도 반복할 수 있는 기반으로 만들었습니다.

한 줄 요약

재고·소진·랜딩·리포트·정산처럼 사람이 기억해 확인하던 업무를 시스템으로 옮겼습니다. 자동화의 목적은 사람을 대체하는 것이 아니라 자료를 모으는 시간을 줄이고 다음 판단과 기획에 집중하게 만드는 것입니다. 6종 모두 데이터가 정상이라는 증거가 없으면 실행하지 않습니다.

재고·소진·랜딩·리포트·정산을 정해진 주기로 확인하는 시스템 6종을 직접 기획·구축해 운영하고 있습니다. 뉴발란스 등 여러 브랜드에 적용했고, 담당자가 바로 이어받을 수 있도록 실행 스크립트와 운영 문서도 함께 만들었습니다.

01

문제 정의

사람이 기억해서 확인해야 하는 업무가 너무 많았습니다. 확인이 늦으면 광고비가 새고, 확인에 시간을 쓰면 판단할 시간이 없었습니다.

02

데이터에서 확인한 것

자동화에서 가장 위험한 실패는 멈추는 것이 아니라 잘못된 데이터로 계속 도는 것이었습니다. 재고 수집이 절반 실패한 상태로 판정을 진행하면 정상 판매 상품이 대량으로 꺼집니다. 그래서 판정의 방향을 뒤집었습니다 — 데이터가 좋다는 증거가 없으면 중단합니다.

03

핵심 판단

실행 속도보다 안전장치를 먼저 설계했습니다. 기준 파일 부재, 표본 0건, 재고 미상 비율 초과, 수집 실패율 초과 중 하나라도 감지되면 광고를 건드리지 않고 작업을 멈춘 뒤 담당자에게 알립니다.

04

실행

  • 쇼핑검색 재고 자동 운영 — 예약 수집, 재고 수량에 따른 광고 중단·재시작, 회당 최대 900개
  • 리포트 자동화 엔진 — RAW 3종 붙여넣기로 대시보드·캠페인 리포트·QC 자동 생성, 매체 별칭 38종·오디언스 82그룹 자동 매핑
  • 이상 징후 자동 모니터링 3건 — 데드랜딩, 소진 흐름, 6개 매체 GA4 데일리 코멘트 예약 실행
  • 광고비 정산 자동화 — 법인카드 증빙을 전자결재에 자동 등록, 월 최대 84건 전량 처리(2026.05)
  • 월간 리포트 자동 발송 시스템 — 12개 핵심 지표를 공통 기준으로 맞춰 PDF 자동 발송 (Python · PostgreSQL · Docker)
  • 업무 지식봇 2종 — 업무 기록 854개 파일을 검색해 근거 파일과 함께 답하는 사내 챗봇

이 시스템들을 무엇으로 평가할 것인가

지금 남아 있는 지표는 절감 시간과 처리 건수입니다. 운영을 넘겨받을 사람이 품질을 판단하려면 아래 항목이 함께 필요하다고 보고, 다음 운영 주기의 측정 기준으로 설계했습니다.

모바일에서는 좌우로 밀어 확인할 수 있습니다.

06

나의 역할

이 케이스의 기여도 100%는 뉴발란스 계정 운영 전체가 아니라 자동화 시스템 6종의 기획·구축·운영 범위입니다. 계정 운영 기여도 40%와 분리해 표기했습니다.

직접 수행

  • 6종 전체의 요건 정의 · 아키텍처 설계 · 코드 작성 · 배포 · 운영
  • 데이터 이상 시 실행을 멈추는 4단계 안전장치 설계
  • LLM 교차검증 발행 규칙
  • 실행 스크립트와 인수인계 문서 작성

함께 수행

  • 전자결재 연동은 사내 시스템 담당 부서와 함께 규격을 맞췄습니다

하지 않은 것

  • 사내 인프라 계정 권한과 보안 정책은 정보시스템 부서 소관입니다
  • 매체 API 사용 계약·한도 협의는 제 범위가 아니었습니다

기여 범위시스템 6종 기획·구축·운영 100%

07

실패와 수정한 판단

되지 않았던 것

초기에는 실행 속도를 우선했습니다. 하지만 재고 수집이 절반 실패한 상태로 판정이 돌면 정상 판매 상품이 대량으로 꺼질 수 있다는 점을 확인했습니다. 이후 데이터에 이상이 있으면 작업을 멈추도록 방향을 바꿨습니다. 자동화에서 더 위험한 실패는 멈추는 것이 아니라 잘못된 데이터로 계속 실행되는 것이었습니다.

다음에 다르게 할 것

자동화는 사람을 대체하는 게 아니라 사람이 판단할 시간을 만드는 일이었습니다. 그래서 '이상하면 멈추고 부르는' 설계가 속도보다 중요했습니다.

08

실행 화면과 증빙

스케줄러 설정 화면과 실행 로그로 보유하고 있으며, 광고주 데이터가 포함되지 않는 범위에서 인터뷰 시 보여드릴 수 있습니다.

09
