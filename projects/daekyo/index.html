대교에듀캠프

CTR 하락을 소재 문제로 단정하지 않고, 전환 경로의 병목부터 다시 봤습니다.

한 줄 요약

‘전년보다 성과가 나빠졌다’는 판단에 소액 고CTR 소재가 섞여 있었습니다. 표본을 맞춰 보니 CVR과 CPA는 오히려 개선됐고, 실제 병목은 소재보다 상담 폼에 가까웠습니다.

기간
2025.11 – 현재
역할
데이터 재검증 · 측정 QA 설계
기여 범위
측정 QA 설계 100%
규모
서브 브랜드 5개 · 학기 단위 운영

근거 형태 — 내부 매체·GA4 비교 리포트

  • CVR 0.66% → 2.24%
  • CPA 68,869원 → 59,169원
  • CTR 2.54% → 2.25%

학습 단계와 전환 정의가 다른 서브 브랜드 5개(마이페이스 · 플래뮤 · 트니트니 · 오감올리 · 크리액팅)를 한 계정에서 학기 단위로 운영합니다. 그중 광고주가 성과 하락으로 판단한 상황을, 표본 왜곡과 전환 경로 문제로 분리해 다시 정의했습니다.

01

문제 정의

전년 대비 성과가 낮아졌다는 판단의 비교 기준에 약 9천 원만 소진된 고CTR 소재가 포함돼 있었습니다. 상담하기 클릭 이후에도 추가 페이지와 다수 입력 항목이 이어지는 구조였습니다.

02

데이터에서 확인한 것

동일 기준으로 다시 비교하자 CTR은 2.54%에서 2.25%로 소폭 낮아졌지만, CVR은 0.66%에서 2.24%로 올라가고 CPA는 68,869원에서 59,169원으로 개선됐습니다. 표면 지표와 실제 효율이 반대 방향이었습니다.

03

핵심 판단

병목을 '소재 반응 저하'로 단정하지 않았습니다. 표본 왜곡과 클릭 이후 상담 폼 이탈을 분리하고, 소재 교체보다 전환 경로 단순화가 우선이라는 가설을 세웠습니다.

04

실행

  • 이름·연락처 중심으로 입력 항목 축소 제안
  • 자사 랜딩과 Meta 인스턴트폼 병행, 폼 유형별 DB 품질 비교
  • GA4·매체·GTM 이벤트를 같은 기준으로 점검하는 QA 체크리스트 설계
  • 브랜드마다 다른 전환 정의(상담 DB · 수강신청 · 창업 DB)를 분리해 서브 브랜드별 QA 기준을 각각 수립
  • 오감올리 여름학기는 소재 6종을 계열별로 나눠 집행하고 반응 차이를 확인(1차 CTR 7.90%·CPC 114원 → 2차 5.72%·147원)

한 광고주 안의 서브 브랜드 5개

대교에듀캠프는 학습 단계와 전환 정의가 서로 다른 브랜드를 한 계정 아래 두고 있습니다. 같은 'DB 전환'이라는 이름이 브랜드마다 다른 행동을 가리켜서, 측정 QA를 계정 단위가 아니라 브랜드 단위로 나눠 설계했습니다.

모바일에서는 좌우로 밀어 확인할 수 있습니다.

브랜드영역전환 정의확인한 수치

플래뮤창업 모집창업 상담 DB26상반기 DB 272건(전년 136건) · 객단가 20만원 → 11만원

크리액팅아동 연극놀이봄학기 수강생 모집미디어믹스 설계 단계

위 수치는 계정별 측정 구조를 설명하기 위한 운영 맥락이며, 전부가 개인 단독 성과라는 뜻이 아닙니다. 제 기여 범위는 측정 QA 설계입니다. 크리액팅은 봄학기 미디어믹스를 설계한 단계까지이며, 결과 리포트를 보유하지 않아 성과 수치를 적지 않았습니다.

클릭 이후 어디서 끊겼는가

표본을 맞춰 다시 계산하니 문제는 소재 반응이 아니었습니다. 상담하기 클릭 다음에 무엇이 이어지는지를 단계로 펴 보고 병목을 다시 잡았습니다.

AS-IS · 클릭 다음에 단계가 더 있었다

① 광고 클릭

② 추가 페이지 경유

③ 입력 항목 다수

④ DB 제출

상담하기를 눌러도 페이지가 한 번 더 끼고, 그다음 입력 항목이 여럿 이어지는 구조였습니다.

TO-BE · 이름·연락처 중심으로 축소

① 광고 클릭

② 폼 직접 노출

③ 이름 · 연락처

④ DB 제출

자사 랜딩과 Meta 인스턴트폼을 함께 돌려 폼 유형별 DB 품질을 비교했습니다.

  • 이탈이 생기던 구간
  • 축소·직접 노출로 바꾼 구간
  • 그대로 둔 구간

화면 캡처가 아니라 전환 경로를 다시 그린 도식입니다. 실제 매체·GA4 비교 리포트는 광고주 보안상 인터뷰에서 확인해 드립니다.

상담 폼 반복 개선

CVR만 높이지 않고 이탈과 DB 품질의 균형을 찾기 위해 세 번 수정했습니다.

  1. 01

    입력 항목 축소

    CVR은 개선됐지만 DB 품질이 낮아졌습니다.

  2. 02

    자격 질문 일부 복원

    의향이 낮은 DB를 한 번 더 걸렀습니다.

  3. 03

    문항 순서 조정

    이탈과 DB 품질의 균형을 조정했습니다.

06

나의 역할

전년 데이터 재검증, 표본 기준 수립, 광고주 설명 논리, 폼 개선안과 측정 QA 기준을 담당했습니다.

직접 수행

  • 전년·현재 성과의 동일 기준 재비교와 표본 기준 수립
  • 폼 유형별 DB 품질 비교 설계와 3차에 걸친 반복 개선
  • GA4·매체·GTM 측정 QA 체크리스트
  • 광고주 설명 논리와 보고 기준 재정의

함께 수행

  • 소재 제작과 랜딩 수정은 제작팀·광고주 개발팀과 함께 진행했습니다

하지 않은 것

  • 상담 이후의 등록 전환은 광고주 내부 프로세스라 측정 범위 밖입니다
  • GTM은 검수 기준과 개선안을 제시한 범위이며, 최종 운영환경 해결로 단정하지 않습니다

기여 범위측정 QA 설계 100%

07

실패와 수정한 판단

되지 않았던 것

1차 인스턴트폼은 CVR은 올랐지만 상담 연결률이 떨어졌습니다. 입력 항목을 줄인 만큼 의향이 낮은 DB가 섞였기 때문입니다. 2차에서 자격 질문 1개를 되돌리고, 3차에서 문항 순서를 바꿔 이탈 구간을 옮겼습니다. CVR을 최대화하는 폼과 DB 품질을 지키는 폼은 다른 폼이었습니다.

다음에 다르게 할 것

지표가 나빠 보일 때 먼저 의심할 것은 소재가 아니라 비교 기준이었습니다. 표본을 맞추자 결론이 반대로 바뀌었습니다.

08

실행 화면과 증빙

매체·GA4 비교 리포트로 보유하고 있으며, 광고주 보안상 인터뷰에서 직접 확인해 드립니다.

09

근거와 산정 기준
