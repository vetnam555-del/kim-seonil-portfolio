# O-10 사례 하나를 외부 글로 쓸지 — 검토 (2026-10-29)

주인 질문: "이건 어떻게 하는 게 좋을 것 같아? 자비스(코덱스)랑 같이 검토해줘."
이 문서는 Claude 안이다. 자비스 의견은 이 문서가 실린 PR 의 검토 응답으로 받는다. 결정은 주인이 한다.
계기는 2026-10-29 레퍼런스(`REFERENCES.md`) — 같은 분석을 긴 외부 글과 상세 페이지로 나눠 올린 형식이다.

## 지금 상태 (사실)

- 사이트는 검색 노출을 막아 두었다(noindex · noarchive · nosnippet, BACKLOG O-01). 열더라도 사례 상세는 계속 막는 안을 권해 왔다.
- 사이트에는 방문 분석 도구가 없다. 외부 글에서 사이트로 몇 명이 왔는지는 잴 수 없다.
- 공개 채널은 링크드인(사이트 연락 구간에 연결)과 EDIT H(2030 직장인 트렌드 뉴스레터, 공개 문서 114편)가 있다. 꾸준히 써서 공개해 온 기록이 이미 있다.
- 사례 수치는 비율 · 증감률로만 쓰고 광고주 금액 · 건수와 로고는 싣지 않는다.
- 2026.10 부터 리멤버앤컴퍼니에 재직 중이다.

## 얻는 것과 드는 것

| 얻는 것 | 드는 것 · 위험 |
|---|---|
| 검색으로 찾을 수 있는 글이 하나 생긴다(사이트는 검색에 안 잡힌다) | 글은 검색에 잡힌다. 광고주 이름과 성과가 같이 검색되면, 사례 상세를 검색에서 막아 둔 이유와 어긋난다 |

| 링크드인 같은 직무 네트워크에 나눌 거리가 생긴다 | 시간이 든다. 첫 문단(왜 이 문제를 봤는지)은 본인 문장이어야 한다 — 지어 쓸 수 없다 |
| | 재직 중인 회사의 외부 기고 · SNS 규정, 전 직장(대행사)과 광고주 자료를 어디까지 쓸 수 있는지 |

## Claude 안 — B 를 한 편만, 조건을 지켜서

쓰기로 한다면 B 를 권한다. 한 편을 써 보고 계속할지는 그다음에 정한다. 당장 시간이 없다면 A 가 맞고, 잃는 것은 없다.

**사례는 대교에듀캠프.**

1. 기여 범위가 100%다(측정 QA 설계). 상담 폼 3차 개선도 본인이 맡은 일로 사례에 적혀 있다 — 공동 성과를 나눠 적는 부담이 없다.
   다이슨(공동 기획 40%) · 제이에스티나(75%) · 뉴발란스(계정 운영 40%)보다 글 한 편으로 설명하기 쉽다.
2. 홈의 TEST 사례이고 첫 화면 소개("비교 기준부터 점검")와 같은 주제다. 글과 사이트가 같은 이야기를 한다.
3. 판단을 뒤집은 과정(표본을 맞추자 결론이 반대)과 그 대가(1차 폼의 DB 품질 하락)가 함께 있다. 레퍼런스 글의 강점인
   "주장 수정 · 한계 인정"을 지어내지 않고 그대로 쓸 수 있다.
4. 업종 일반의 교훈이라 광고주 이름 없이도 읽힌다.

다음 후보는 뉴발란스의 17.6% 격차(98.5%가 매칭 범위 차이) — 데이터 검증 이야기다. 같은 업무가 LG CNS MOP 우수사례로
이미 공개돼 있어 노출 부담은 작은 편이지만, 자동화 부분은 AI 도구를 쓴 범위를 같이 적어야 해서 글이 길어진다.

**플랫폼.** 원문은 한 곳, 링크드인에는 3–5줄 요약과 링크. 원문 자리는 브런치(국내 마케터 독자가 많고 작가 신청 승인이 필요하다)나
미디엄(승인 없이 바로, 국내 독자는 적다) 가운데 고른다. 어디에 올릴지는 회사 규정을 확인한 뒤 정한다.

## 하지 않을 것

- 재직 중인 회사의 업무 · 데이터 · 서비스에 대한 의견을 쓰지 않는다.
- 광고주 이름을 제목 · 첫 문단에 쓰지 않는다(본문에서도 "교육 서비스 리드 캠페인"처럼 업종으로). 금액 · 건수는 쓰지 않는다.
- 사이트 사례에 없는 숫자를 새로 쓰지 않는다. 표본 재비교(전년 대비)와 폼 테스트(2026.05 → 06)는 기간이 다르다 — 섞지 않는다.
- 레퍼런스 글의 문장 · 구성을 옮기지 않는다(형식만).
- 사이트 검색 노출(O-01)은 이 결정과 따로 둔다. 글을 올려도 사례 상세는 지금처럼 막아 둔다.

## 초안 개요 (대교 — 사례에 있는 사실만)

제목 안: "성과가 떨어졌다는 진단, 소재보다 비교 표본부터 다시 봤습니다"

1. 진단 — 전년보다 성과가 낮아졌다는 판단을 받았다. *(첫 문단의 계기와 느낌은 본인 문장)*
2. 비교 기준 — 비교에 약 9천 원만 쓴 고CTR 소재가 섞여 있었다. 같은 기준으로 다시 계산하자 CTR 2.54% → 2.25%,
   CVR 0.66% → 2.24%, CPA 14.1% 개선. 겉으로 보이는 지표와 실제 효율이 반대였다.
3. 병목 — 상담하기를 누른 뒤에도 추가 페이지와 여러 입력 항목이 이어지는 구조였다.
4. 상담 폼 세 차례 — 1차 인스턴트폼은 CVR 이 올랐지만 의향이 낮은 DB 가 섞여 상담 연결률이 떨어졌다. 2차에 자격 질문 1개를
   되돌리고 3차에 문항 순서를 바꿨다. 인스턴트폼을 다시 도입한 6월, 광고 DB 전환율 2.84% → 7.55% · CPA 47.6% 개선.
   정규 서비스 전환율은 13.7% → 9.9% 로 낮아졌고 7월 이후 문항을 다시 조정해 11.28% 로 일부 회복했다.
5. 어디까지 했나 — GTM 검수 기준과 개선안은 제안까지 했다. 상담 이후 등록 전환은 광고주 월간 결산보고의 비율로 봤다.
6. 배운 것 세 줄 — 지표가 나빠 보이면 소재보다 비교 대상부터 확인한다 / CVR 을 최대로 올리는 폼과 DB 품질을 지키는 폼은
   다른 폼이다 / 표본을 맞추자 결론이 반대로 나왔다.
7. 끝 — 포트폴리오 사례 링크 한 줄.
