# 링크드인 프로필 원문 (v4 · 2026-10-31)

사이트 밖의 공개 프로필이다. 이 저장소에서 빌드하지 않는다. 주인이 직접 붙여 넣거나, 브라우저를 다룰 수 있는 에이전트
(Claude 데스크톱 앱의 내장 브라우저 · 크롬 확장)가 **주인이 직접 로그인한 화면**에서 넣는다. 클라우드 세션은 링크드인을 열지 못한다
(로그인이 필요하고 자동 접속은 999 로 막힌다).

v4 는 2026-10-31 실제 프로필에 반영한 결과다(같은 날 밤 주인 승인으로 더 고친 곳과 최종 점검 포함 — 맨 아래 '어떻게 정했나').
반영한 뒤 데스크톱 앱 내장 브라우저로 칸마다 다시 읽어 이 문서를 맞췄다(읽기만 했다).

## 주인 결정 (2026-10-31)

- 경력 직함은 직무명을 붙인다(O-11): `광고사업실 매니저 · 퍼포먼스 마케터` / `과장 · 퍼포먼스 마케터` / `PM · 퍼포먼스 마케터` / `인턴`.
- 공개 범위는 이력서 수준 — 광고주 이름 + 비율(O-11).
- 헤드라인에 연차를 쓰지 않는다.
- 웹 포트폴리오 주소는 링크드인에 공개하지 않는다 — 연락처 웹사이트 칸 없음, Featured 는 MOP 우수사례 · EDIT H 두 개,
  소개 · 프로젝트 칸에 사례 페이지 링크 없음.
- 전화번호는 연락처에 둔다. v3 '지킬 것'(전화번호를 넣지 않는다)을 주인이 바꿨다. 번호는 이 문서에 적지 않는다.

- 학력은 링크드인에 원래 있던 그대로 둔다(9절). 사이트 · 이력서의 학력(BACKLOG '정해 둔 것' 2026-10-24 — 학점은행제 학위 줄,
  숭실대는 학교 이름과 기간만)과 다르다.
- 리멤버 부서 이름은 **광고사업실**이다. 사이트 · 이력서 PDF · 포트폴리오 PDF 에 남은 '광고운영팀'은 BACKLOG B-15 로 고친다.

## 적용할 때 지킬 것

- 이 문서에 없는 사실 · 숫자를 만들지 않는다. 숫자는 기준과 함께 쓴다 — 링크드인 설명은 괄호 대신 문장 안에 기준을 넣는다(v4).
- 수상은 '통합 퍼포먼스 부문 우수상'까지 쓴다. "디지털 광고 대상 수상"으로 줄이면 대상을 받은 것으로 읽힌다.
- 저장할 때 '네트워크에 알리기'는 끈다. 구직 중(Open to Work)은 켜지 않는다(재직 중, 2026-10-15 결정).
- 프로필 주소(URL) · 이름 · 사진은 건드리지 않는다(이력서 · 사이트에 지금 주소가 실려 있다). 거주지 주소는 넣지 않는다.
  전화번호는 주인 결정으로 연락처에 있다 — 지우지도, 이 문서에 옮기지도 않는다.
- 웹 포트폴리오 주소를 어느 칸에도 넣지 않는다(주인 결정).
- 로그아웃하거나 계정 · 개인정보 · 공개 범위 설정을 바꾸지 않는다. 비밀번호 · 인증 코드가 필요하면 멈추고 주인에게 넘긴다.

## 고칠 때 순서 (에이전트)

1. 프로필 첫 화면과 상세 화면을 접힌 '더보기'까지 읽는다. 상세 화면은 프로필 주소 뒤에 `details/experience/` · `details/projects/` ·
   `details/certifications/` · `details/honors/` · `details/skills/` · `details/education/` · `details/languages/`, 연락처는 `overlay/contact-info/` 다.
   새 링크드인 화면은 브라우저 창이 숨겨져 있으면 학력 · 보유기술 칸을 그리지 않는다 — 창을 보이게 하고 읽는다.
   수상 상세 화면은 처음에 10개만 그리고 끝까지 내려야 나머지를 불러온다 — 개수를 센 뒤 대조한다(2026-10-31 처음 대조 때 17개 중 10개만 읽었다).
2. 이 문서와 칸별 대조표를 주인에게 보인다 — 지금 내용 / 이 문서 / 차이(빠진 칸, 다른 문장 · 숫자, 오타, 줄바꿈 깨짐).
3. 주인이 확인하면 칸 하나씩 고친다. 바꾸기 전에 지금 내용과 바꿀 내용을 보여 주고, 저장은 주인이 좋다고 한 뒤에만.
4. 끝나면 다시 읽어 이 문서를 실제 프로필에 맞춘다. 위 표의 '상태'와 맨 아래 '남은 차이'를 고친다.
