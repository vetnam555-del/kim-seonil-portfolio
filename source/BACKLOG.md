# 개선 백로그 · 점수표

포트폴리오를 계속 손보기 위한 기준표다. 매주 월요일 정기 점검(`npm run health:full`)의 결과와 대화로 들어온 새 성과를
여기에 모은다. 작업 순서·원칙은 저장소 루트 `.claude/skills/portfolio-steward/SKILL.md` 에 있다.

- 점수는 아래 **채점 기준**으로만 매긴다. 근거 없이 올리거나 내리지 않는다.
- 항목을 끝내면 `완료 기록`으로 옮기고 커밋을 적는다. 지우지 않는다.
- 주인의 결정이나 자료가 필요한 일은 `주인 확인` 에 두고, 추측으로 채우지 않는다.
- 다른 포트폴리오에서 가져올 아이디어는 `REFERENCES.md` 에 근거를 적고 여기 `R-` 번호로 넣는다.

- 라이브가 main 과 다르거나 이력서에 전화번호·주소·생년월일이 보이면 점수와 상관없이 **그 주 최우선 결함**이다.
- 403·429·999(LinkedIn) 같은 차단 응답은 결함이 아니다. 주인이 브라우저로 확인한다(O-04).
  5xx 는 3초 뒤 다시 물어도 실패할 때 경고로 남긴다(일시적 장애가 많다). 두 주 연속이면 확인한다.
- 측정하지 못한 값에는 점수를 매기지 않는다. Lighthouse 세 화면 중 하나라도 실패하면 접근성·CLS 종합값을 내지 않고
  "측정 불완전"으로 적는다. 이력서 글자 추출이 실패하거나 글자가 거의 없으면 개인정보 검사를 "확인 불가" 결함으로 센다.
- Lighthouse 는 화면마다 3번 재서 성능 중앙값 회차를 쓴다(같은 날도 69–73 처럼 흔들린다).
- `npm run health:full` 보고서의 "측정 점수" 절이 이 표를 그대로 계산한다. 구간을 바꾸면 `scripts/health_check.mjs` 도 같이 고친다.
